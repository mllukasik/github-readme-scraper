# github-readme-scraper

## About

GitHub Action to scrap README.d files from repositories.
Created as small addition to [bobo-generator](https://github.com/mllukasik/bobo-generator) to generate portfolio based
on GitHub repositories.

## Inputs

| Name     | Type   | Description         |
|----------|--------|---------------------|
| `name`   | String | Github account name |
| `output` | String | Output directory    |
